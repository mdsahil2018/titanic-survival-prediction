# Titanic Survival Prediction

Machine learning model built with Python, Pandas, and Scikit-learn to predict 
passenger survival on the Titanic dataset.

## What it does
- Cleans raw data (handles missing values in Age, Embarked; drops Cabin)
- Encodes categorical feature (Sex)
- Trains a Logistic Regression model
- Achieves 80% accuracy on test data

## Tech used
Python, Pandas, Scikit-learn
